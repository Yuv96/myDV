抖音抬头版 0.1.2，包名 `com.dycomment.tv.android5`，版本号 1007，支持 Android 5.0 及以上。

## 界面更新

- 评论区改为只读滚动，移除焦点与底部按钮；触底自动加载下一页，内存保留最近 200 条但不停止继续向后阅读。
- 正文 20sp、昵称和点赞数 10sp，固定大小头像靠右，不添加编号前缀。
- 右上角胶囊合并时间、通知数和“未登录”，移除居中的权限提示；淡化分隔线，增大两侧间距。
- 新增极简 TV 图标、各分辨率启动图标、自适应图标和带应用名称的 320×180 Android TV 横幅。

## 覆盖安装与签名

正式构建不再回退到临时签名。发布流程要求新 APK 与 a5.4、v0.1.1 发布包的真实签名证书完全一致，并在 API 21 模拟器执行连续覆盖安装和私有数据保留验证。公开证书指纹见 `SIGNING_CERTIFICATE.txt`，安装包摘要见 `SHA256SUMS.txt`。

此前从 Actions 下载的临时签名包不能覆盖正式版本；不要通过卸载已登录旧版来解决此次构建签名错误。此发布附件只在证书一致及升级验证通过后生成。

## 接口限制

网页扫码取凭证、账号与好友列表读取、网页点赞及取消点赞已联调。电视端独立扫码轮询仍可能返回 4031；电视端动态签名、真实评论读取、关注与好友分享送达尚未全部打通。界面与合成分页回归不能替代这些真实接口验证，本版不承诺新安装后一定能扫码登录。

所有构建、回归、签名及升级安装检查均在 GitHub Actions 执行，个人凭证不进入构建产物。
