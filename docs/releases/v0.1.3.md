抖音抬头版 0.1.3，包名 `com.dycomment.tv.android5`，版本号 1008，支持 Android 5.0 及以上。

## 界面

- 评论头像改为圆形，包含占位背景和已加载图片；固定大小、右侧位置和只读滚动保持一致。
- 创作者、博主、个人主页及精选、搜索统一黑底、白字和粉色焦点样式，去除旧渐变与装饰。
- 应用菜单改用纯文字，避免旧电视缺少 emoji 字形；用户昵称、评论等原始内容不变。

## 登录

移除电视端自行拼接 Passport 二维码请求的登录路径，改用可见的官方网页完成扫码、轮询及验证。方向键移动网页光标，确定点击，返回回到操作按钮。新凭证只有通过独立账号接口验证后才保存，失败或退出保留原账号。

同一开发网络实测：旧简化接口取码成功后轮询返回 4031，官方网页持续返回等待扫码。官方请求包含动态签名和设备上下文；尚不能将 4031 唯一归因于某一个字段，也不能称为电视被封禁。

旧电视的 WebView 内核可能无法运行当前抖音网页；API 21 界面、安全和生命周期回归不等于真实电视扫码成功。评论、点赞、关注、分享还涉及各自的权限和动态签名，本版不承诺扫码后这些接口全部可用。

## 签名与升级

继续使用找回的原正式密钥。发布前验证 a5.4、v0.1.1、v0.1.2 的证书一致，并在 GitHub API 21 模拟器进行连续覆盖安装及应用私有数据保留检查。所有编译和测试在 GitHub Actions 执行。
