抖音抬头版 0.1.1 测试版，包名 com.dycomment.tv.android5，内部版本号 1006，支持 Android 5.0 及以上。

## 本次改动

资料卡在当前视频首次出画面后只显示 3 秒，循环播放不重复出现；切走再切回重新显示。菜单键临时召回，退出右侧菜单立即隐藏。

头像和资料卡整组靠左，最大到屏幕中线；卡片自适应宽度、稳定高度、标题两行省略。圆形头像保持正方形且与卡片同高，底部增加关注状态标签。菜单补齐已/未关注、点赞、收藏，未登录、读取中、状态未知单独显示。

时间和通知计数移到左上角，资料卡不再显示清晰度。修复菜单焦点问题。参考公开实现修正好友分享的视频卡片、设备标识和回执判断，并补齐部分扫码请求字段。

## 已知限制

扫码登录仍未打通，取码可能返回 4031；本版不承诺新安装后能够登录。好友分享真实送达、关注/点赞/收藏与通知计数的真实账号联调仍未验证。左上角数字是通知计数，不是私信未读数；直播弹幕真实显示仍需实测。

## 安装与验证

已登录的旧版用户请覆盖安装，保留账号和设置，不要先卸载。发行流程要求签名证书与已发布 a5.4 一致；签名不符时不会发布 APK。

本版需通过 API 21 模拟器播放与菜单回归、生产包检查及签名一致性检查后发布。SHA256SUMS.txt 提供 APK 校验值。生产安装包不包含内部测试页面或测试视频。
