# 版本记录

## 0.1.0

项目更名为“抖音抬头版”，显示版本重新从 0.1.0 开始；安装版本号继续增长为 1005，以支持覆盖安装。

菜单按内容、播放、界面、账号分组。评论区采用相同的黑粉白样式及复用列表，个人与作者主页调整为相同配色。资料卡保留头像外置、同行数据和 48dp 底部安全区。关于页只保留来源、操作说明和本仓库 Issues 联系入口。

移除汽水音乐及手工、局域网凭证输入页面，移除共享 Cookie、共享固定 Token 和不再参与播放的本地视频代理实现。账号页接入官方 QR 申请与轮询、受限跳转、登录验证和原子替换前的旧账号保留。**当前网络的官方接口拒绝签发二维码（4031），真实扫码登录未验证；未实现可靠的自动评论动态签名，不能保证扫码后评论即可恢复。** 现有个人配置保留，不会在申请失败时清空。

优化主页和列表缩略图的下载、队列、解码及缓存上限。页面关闭清理图片任务、评论任务、通知刷新和播放超时回调。推荐列表不再无限保留历史。正式构建去除内部测试 Activity 和生成视频，回归构建单独输出。

仍保留的限制：好友分享真实送达未验证；直播轮询在此前实测只返回游标，真实弹幕显示未验证；通知角标不是私信未读数；API 21 使用半透明背景而非实时模糊。长时间真机内存表现仍需实测。

旧版工程记录见 [历史目录](history/)。
